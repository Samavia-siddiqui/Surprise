# Surprise

A lightweight front-end project built with HTML, CSS, and JavaScript.

## Overview

Surprise is a small web project that demonstrates interactive UI elements using JavaScript, styled with modern CSS, and structured with semantic HTML. It's intended as a starting point or demo for small web interactions.

## Features

- Responsive layout using CSS
- JavaScript-driven interactivity
- Simple, easy-to-read codebase for learning and modification

## Getting started

1. Clone the repository:

   git clone https://github.com/Samavia-siddiqui/Surprise.git

2. Open index.html in your browser:

   - Double-click the `index.html` file, or
   - Serve it with a static server (recommended for modules or fetch usage):

     npx http-server .

## Development

- Edit HTML files in the project root to change structure.
- Modify CSS files in the `styles` (or root) folder to update styling.
- Update JavaScript in the `scripts` (or root) folder for behavior.
